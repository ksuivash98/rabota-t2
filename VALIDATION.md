# Проверка реализации

## Исправление GitHub Pages

Исходники перенесены в `site/`. Vite использует base `/rabota-t2/`. После `npm run build` скрипт `scripts/sync-pages.mjs` сохраняет готовые HTML, CSS, JS и шрифты в корне репозитория. `.nojekyll` отключает обработку файлов Jekyll. Публикация предназначена для GitHub Pages из `main`, каталога `/ (root)`.

- `npm run build` — успешно.
- `CHROMIUM_PATH=/usr/bin/chromium npm test` — 13 пройдено, 1 пропущен (мобильное меню неприменимо на desktop).
- Тесты отдают **готовые корневые файлы статическим сервером**, без Vite, по адресу `/rabota-t2/`. Проверяются фактически применённые цвета и подключение шрифта, путь JS, форма, четыре салона, меню и клавиатурная навигация.
- Проверены ширины 320, 390, 768, 1024 и 1440 px. Переполнения нет. Скриншоты desktop/mobile обновлены в `artifacts/` (не включены в Git).
- Среда: системный Chromium, desktop и эмуляция iPhone 13. Реальные Safari/Firefox и физический телефон не проверялись.

Прямой запрос к `https://ksuivash98.github.io/rabota-t2/` и GitHub Pages API из облачной среды отклонён сетевым прокси (403). Поэтому локальная проверка готовой публикации подтверждена, но обновление удалённого Pages и его настройки из этой среды не подтверждены. После push GitHub должен выполнить обычную публикацию из `main` / root; статус можно посмотреть в GitHub Actions / Pages.

## Анимация заголовка и пунктуация

Добавлен эффект печати/стирания с курсором, паузой, поддержкой reduced motion и статического HTML без JavaScript. Проверены неизменность размеров заголовка, полный доступный текст, печать, стирание и управление паузой на desktop/mobile. Полный текущий прогон: 17 пройдено, 1 проверка мобильного меню пропущена на desktop. Конечные точки в видимых текстовых блоках и динамических сообщениях удалены, надпись «ЛЮДИ. ТЕХНОЛОГИИ. ТЫ.» сохранена.

## Анимации остальных заголовков и контраст

FoldText адаптирован для блоков возможностей и этапов трудоустройства: раскрытие букв сверху при входе в область просмотра. StrokeText — для карьерного заголовка: прорисовка контуров и заливка слева направо. TextType применён к салонам с отдельной кнопкой паузы. ShinyText — один двухсекундный проход светового блика по контактному заголовку. Все эффекты сохраняют исходный текст, цвета акцентов и поддерживают reduced motion; статический HTML остаётся доступным без JavaScript.

«Подробнее» увеличено до 18 px. Приглушённый текст заменён контрастным чёрным на светлом фоне и белым на тёмном. Полная проверка текущей сборки: 27 пройдено, 1 проверка мобильного меню пропущена на desktop. Проверены запуск эффектов при прокрутке, финальная читаемость, отсутствие изменения геометрии, режим уменьшения анимации, адаптивность, навигация и форма.

## Удаление анкеты

По последнему запросу пользователя анкета, предупреждения о подключении и клиентская валидация удалены. Отклик осуществляется напрямую через MAX или звонок. Выбор салона показывает название рядом с контактами и переводит фокус на кнопку MAX. Сайт не собирает анкетные данные. Текущая сборка: 25 проверок пройдено, одна неприменимая проверка мобильного меню пропущена на desktop. Ранее описанные проверки анкеты относятся к предыдущим версиям.
