# Проверка реализации

## Исправление GitHub Pages

Исходники перенесены в `site/`. Vite использует base `/rabota-t2/`. После `npm run build` скрипт `scripts/sync-pages.mjs` сохраняет готовые HTML, CSS, JS и шрифты в корне репозитория. `.nojekyll` отключает обработку файлов Jekyll. Публикация предназначена для GitHub Pages из `main`, каталога `/ (root)`.

- `npm run build` — успешно.
- `CHROMIUM_PATH=/usr/bin/chromium npm test` — 13 пройдено, 1 пропущен (мобильное меню неприменимо на desktop).
- Тесты отдают **готовые корневые файлы статическим сервером**, без Vite, по адресу `/rabota-t2/`. Проверяются фактически применённые цвета и подключение шрифта, путь JS, форма, четыре салона, меню и клавиатурная навигация.
- Проверены ширины 320, 390, 768, 1024 и 1440 px. Переполнения нет. Скриншоты desktop/mobile обновлены в `artifacts/` (не включены в Git).
- Среда: системный Chromium, desktop и эмуляция iPhone 13. Реальные Safari/Firefox и физический телефон не проверялись.

Прямой запрос к `https://ksuivash98.github.io/rabota-t2/` и GitHub Pages API из облачной среды отклонён сетевым прокси (403). Поэтому локальная проверка готовой публикации подтверждена, но обновление удалённого Pages и его настройки из этой среды не подтверждены. После push GitHub должен выполнить обычную публикацию из `main` / root; статус можно посмотреть в GitHub Actions / Pages.
