# Проверка реализации

- `npm ci --cache /tmp/t2-npm-cache` — успешно, установка по lockfile.
- `npm run build` — успешно.
- `CHROMIUM_PATH=/usr/bin/chromium npm test` — 11 пройдено, 1 пропущен (мобильное меню неприменимо на desktop).
- После замены иконок на SVG сделана визуальная проверка desktop/mobile.
- После финального увеличения мобильных текстов повторены проверки переполнения и мобильный скриншот.
- `npm audit --omit=dev` — у production-зависимостей уязвимости не обнаружены на момент проверки.

Проверены: четыре точных адреса, шесть раскрывающихся преимуществ, выбор каждого салона, валидация пустых и неверных полей, клавиатурные вкладки этапов, открытие/закрытие мобильного меню, отсутствие HTTP-отправки и localStorage для заявки, отсутствие переполнения на ширинах 320, 390, 768, 1024, 1440 px.

Среда проверки: системный Chromium, desktop и эмуляция iPhone 13. Проверки в реальном Safari/Firefox и на физическом телефоне не проводились. Скриншоты находятся в `artifacts/` (не включены в Git).

Публикация и удаление старого проекта **не выполнены**: инструменты Sites недоступны. Добавлены предоставленные пользователем контакты: телефон и MAX. Автоматический приём анкет намеренно выключен. Новый публичный/приватный адрес не создан.
