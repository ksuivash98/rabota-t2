# t2 · Березники — карьера

Новый адаптивный карьерный сайт. Vanilla JavaScript, Vite, локальный Manrope, CSS-композиция смартфона без тяжёлых изображений. Внешних сервисов аналитики и загрузки шрифтов нет.

## Запуск

Нужен Node.js 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Продакшен: `npm run build`. Содержимое `dist/` можно разместить на статическом хостинге. Для локальной проверки сборки: `npm run preview`. При публикации в Sites сначала используйте приватный доступ и проверьте опубликованный адрес. Средства Sites в сессии разработки отсутствовали; публикация не выполнена, старый сайт не удалён.

## Проверки

```sh
npx playwright install chromium
npm run build
npm test
```

Если Chromium уже установлен: `CHROMIUM_PATH=/usr/bin/chromium npm test`. В облачной среде браузеры Playwright можно установить в доступный каталог, задав `PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright` при установке и запуске тестов.

Тесты проверяют desktop/mobile, четыре салона, передачу выбора в форму, валидацию, отсутствие отправки и хранения данных, клавиатурные вкладки, мобильное меню и переполнение на ширинах 320–1440 px. Скриншоты сохраняются в `artifacts/`. Тесты запускают отдельный preview-сервер на порту 4180, без использования сервера разработки.

## Приём заявок — ожидает подключения

Добавлены прямые контакты работодателя: +7 (902) 800-88-02 и предоставленная пользователем ссылка MAX. Кнопки открывают телефонное приложение и профиль MAX; отправку сообщения выполняет сам кандидат. Принадлежность профиля подтверждена только данными пользователя. Форма **не отправляет и не сохраняет** данные и не показывает ложного успеха. Валидная форма сообщает, что приём не подключён.

Для подключения нужны:

- Юридическое наименование оператора персональных данных и политика их обработки.
- Для отправки анкеты требуется серверный приём заявки с доставкой работодателю. Прямые ссылки MAX и звонка уже добавлены; переход по ссылке сам по себе не является отправкой заявки.
- Для автоматической доставки — документированный серверный API/интеграция и защищённые переменные окружения; секреты не размещать в клиентском коде или репозитории.

До включения приёма необходимо добавить сведения об операторе, политику, согласие и серверную валидацию, защиту от спама и проверку ошибок доставки. Успешный статус показывать только после подтверждённого приёма сервером. Не передавать имя/телефон через URL, аналитику или localStorage.

Условия зарплаты и стажировки взяты из задания заказчика. Перед публичным запуском работодатель должен подтвердить их актуальность. Отзывы, фотографии сотрудников и вымышленная статистика отсутствуют.

## Структура

- `index.html` — SEO, содержание, семантическая структура и форма.
- `src/styles.css` — визуальная система, адаптивность и reduced motion.
- `src/main.js` — меню, выбор салона, вкладки этапов и валидация.
- `tests/site.spec.js` — браузерные сценарии.
