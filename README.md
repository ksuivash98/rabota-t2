# t2 · Березники — карьера

Новый адаптивный карьерный сайт. Vanilla JavaScript, Vite, локальный Manrope, CSS-композиция смартфона без тяжёлых изображений. Внешних сервисов аналитики и загрузки шрифтов нет.

## Запуск

Нужен Node.js 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

## Публикация на GitHub Pages

`npm run build` собирает сайт и обновляет готовую публикацию в корне репозитория: `index.html`, `assets/`, `favicon.svg`, `manrope-OFL.txt` и `.nojekyll`. Эти файлы хранятся в Git, чтобы GitHub Pages мог показывать сайт из ветки `main`, каталога `/ (root)`, без npm и Vite на сервере.

Адрес публикации: https://ksuivash98.github.io/rabota-t2/. Пути к ресурсам учитывают `/rabota-t2/` в `vite.config.js`.

При каждом изменении: отредактируйте исходники в `site/`, выполните `npm run build`, проверьте результат и отправьте в Git как исходники, так и обновлённые файлы публикации. Корневой `index.html` и `assets/` генерируются — не редактируйте их вручную. Скрипт обновляет только перечисленные генерируемые пути, а не весь checkout.

Для локальной проверки Vite-сборки: `npm run preview`, страница `/rabota-t2/`. Исходная версия для разработки: `npm run dev`, страница `/rabota-t2/`.

Приватная публикация Sites и удаление старого проекта Sites не выполнялись: инструменты Sites в сессии недоступны. GitHub Pages — отдельный способ размещения.

## Проверки

```sh
npx playwright install chromium
npm run build
npm test
```

Если Chromium уже установлен: `CHROMIUM_PATH=/usr/bin/chromium npm test`. В облачной среде браузеры Playwright можно установить в доступный каталог, задав `PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright` при установке и запуске тестов.

Тесты проверяют desktop/mobile, четыре салона, передачу выбора в форму, валидацию, отсутствие отправки и хранения данных, клавиатурные вкладки, мобильное меню и переполнение на ширинах 320–1440 px. Скриншоты сохраняются в `artifacts/`. Тесты запускают отдельный статический сервер на порту 4180, без использования сервера разработки. Сервер отдаёт файлы публикации из корня, без преобразований Vite, по пути `/rabota-t2/`.

## Приём заявок — ожидает подключения

Добавлены прямые контакты работодателя: +7 (902) 800-88-02 и предоставленная пользователем ссылка MAX. Кнопки открывают телефонное приложение и профиль MAX; отправку сообщения выполняет сам кандидат. Принадлежность профиля подтверждена только данными пользователя. Форма **не отправляет и не сохраняет** данные и не показывает ложного успеха. Валидная форма сообщает, что приём не подключён.

Для подключения нужны:

- Юридическое наименование оператора персональных данных и политика их обработки.
- Для отправки анкеты требуется серверный приём заявки с доставкой работодателю. Прямые ссылки MAX и звонка уже добавлены; переход по ссылке сам по себе не является отправкой заявки.
- Для автоматической доставки — документированный серверный API/интеграция и защищённые переменные окружения; секреты не размещать в клиентском коде или репозитории.

До включения приёма необходимо добавить сведения об операторе, политику, согласие и серверную валидацию, защиту от спама и проверку ошибок доставки. Успешный статус показывать только после подтверждённого приёма сервером. Не передавать имя/телефон через URL, аналитику или localStorage.

Условия зарплаты и стажировки взяты из задания заказчика. Перед публичным запуском работодатель должен подтвердить их актуальность. Отзывы, фотографии сотрудников и вымышленная статистика отсутствуют.

## Структура

- `site/index.html` — исходные SEO, содержание, семантическая структура и форма.
- `index.html`, `assets/` — готовая публикация для GitHub Pages.
- `site/src/styles.css` — визуальная система, адаптивность и reduced motion.
- `site/src/main.js` — меню, выбор салона, вкладки этапов и валидация.
- `tests/site.spec.js` — браузерные сценарии.
- `tests/serve-pages.mjs` — статическая проверка публикации.
- `scripts/sync-pages.mjs` — обновление файлов публикации после сборки.

Облачные задачи уже изолированы: работайте в существующем checkout, не создавайте Git worktree без прямого запроса.
